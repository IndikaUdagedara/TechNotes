How to push a home-manager (HM) build to Cachix: 1) Auth once with 'cachix authtoken <token>' or export CACHIX_AUTH_TOKEN. 2) Build then push: 'nix build .#homeConfigurations."telstra".activationPackage --json | jq -r '.[].outputs.out' | cachix push telstra' (replace 'telstra' with the actual cache name and flake attribute). 3) Alternative: 'home-manager build --flake .#telstra' then 'cachix push telstra ./result'. 4) Or auto-push everything while building: 'cachix watch-store telstra &' then 'home-manager switch --flake .#telstra'.
